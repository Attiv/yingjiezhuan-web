# 三國志英傑傳 · 網頁版

《三國志英傑傳》（KOEI，1995，PC DOS 繁體中文版）的网页版复刻，非官方。
**整部游戏**：从序章「群雄起兵討伐董卓」开始的全部剧情、70 场战斗、营地编成与商店、部队配置（布阵）、
装备与转职、全 37 条策略（含回复、士气、混乱与策略书）、单挑演出、棋子逐帧行走、
原版 BGM（按剧情、战斗阶段与单挑换曲）与 21 个动作音效、胜败结算（军资、经验与升级），
纯前端，本地存档，无后端。
音效是 CC0 替代素材，**不是原版 DOS 的效果音**（原版走 `SBOPL2.COM` 的 OPL 合成，尚无可用的提取器）。

内容全部是数据，格式见 [docs/framework.md](docs/framework.md)：5991 步流程、610 幕插剧、
70 场战斗、58 张战场地图、129 名武将、63 件道具（价格、回复量、装备加成、8 条转职链）、37 条策略，
由 `tools/build_campaign.py` 从原版盘转出；剧情画面的**舞台调度**（每幕用哪张宫殿图、
场上摆了谁、哪句话时走动退场、点谁能听他说什么）由 `tools/build_stages.py` 转成
`src/data/stages.json`。
规则数据直接读自原版文件，核心规则在原版程序里反汇编核对过；证据、状态和已知差异都在
[docs/rules.md](docs/rules.md)。**可玩不等于已对齐原版**：两个状态分开写在那份文档的开头。

## 命令

```bash
npm install
npm run dev -- --port 5273      # 开发服务器 http://127.0.0.1:5273
npm test                        # 规则层、剧情与整部剧本数据的自动化测试（Vitest）
npm run typecheck               # 类型检查
npm run build                   # 生产构建到 dist/
npm run preview -- --port 5274  # 预览生产构建 http://127.0.0.1:5274
node tests/e2e.mjs              # 浏览器实操验证（需要开发服务器在 5273）
node tests/prod-smoke.mjs       # 生产构建冒烟（需要预览服务器在 5274）

python3 tools/build_campaign.py                            # 原版剧本/战斗/武将/道具/策略 → src/data/*.json
python3 tools/build_stages.py                              # 剧情舞台：地图、摆人、地名条、点人的台词 → src/data/stages.json
python3 tools/make_full_assets.py <EXTRACT> <PACK>          # 原版图与音乐 → public/assets/**
python3 tools/make_sfx.py                                  # CC0 动作音效 → public/assets/sfx/
python3 tools/extract.py "<原版目录>"                       # 单关数据与数值表（早期工具）
python3 tools/make_original_assets.py <EXTRACT> <PACK>     # 单关素材（早期工具）
python3 tools/make_assets.py <四样素材的路径>               # 旧版：换回不含原版素材的 CC0/公有领域画面
```

浏览器脚本用 `~/.cache/ms-playwright` 里的 Chromium；换别的浏览器设环境变量 `CHROME=/path/to/chrome`。

## 操作

- 剧情里点对话框或按回车、空格翻到下一句；章节横幅点一下继续；遇到选择必须点其中一项。
  序章按原始指令顺序播放人物行走、退场、换图和对白；野外使用完整行军地图并跟随人物滚屏。
  到陈留营帐后可自由点人交谈：公孙瓒、陶谦交谈后才参战，道具屋提供原始货单；
  「編成・道具」和商店均可返回营帐，点关羽确认出征，选择「否」则留在营帐继续准备。
  第一章界桥篇新增六个分阶段交谈点：平原兄弟议事、简雍来访、使者来访、听完求援后准备出发，以及广川、信都战后准备。
  各阶段使用对应原始闲谈；简雍交谈后才入队，使者随后进场。广川道具屋可购物并返回，出发确认可取消。
  北海战后议事厅也可停留交谈：孔融赠金500后，点孔融、太史慈闲谈，点关羽确认出发；取消或读档不重复奖励。
  确认后才给太史慈、陶谦增加原始记录规定的4级、6级，再播放糜竺提示并行军徐州。
  徐州议事厅先自由交谈，点陶谦讨论后再决定路线：点关羽确认出战并行军小沛，或点张飞确认求和；选否或 Esc 留在当前阶段，两阶段均可存读档。
  求和返回徐州后先自由交谈，点陶谦触发受托与雌雄双剑（仅求和路线），再点孙乾才入队前往小沛；小沛点赵云后播放告别并离队。
  城镇自由行走、酒馆打探和原版地点触发仍未实现；其余后续章节继续使用台词对齐调度和闲话模式，演出速度尚未逐帧校准。
- 出兵准备（营地）：左边编成（必带的人锁定，点「出陣／待命」切换），右边道具（包袱 ↔ 武将 8 格，
  能转职的道具旁有「轉○○」）、武将情报与商店（原版定价，点价钱买），底部「存檔」「出陣」。
- 出陣后是**部隊配置**：点蓝色出兵格依次摆人，点已摆好的收回，「自動配置」按关卡出兵位摆好，
  全摆完才能「開始」。
- 左键点我军部队：选中并显示**蓝色可移动格**和**橙色攻击范围**（走过去能打到哪儿）。
  再点范围内的格子移动，点部队自己则原地下令。
  移动时棋子按原版 `HEXZCHR` 的站立 / 迈步两帧逐格交替，每格配脚步声，水平转弯立即改变朝向；
  走完保留最后方向，取消移动恢复原方向，攻击音效在命中时播放；
  站着不动的部队会像原版那样轻轻起伏（待机呼吸）。
- 移动后弹出指令菜单：攻击、策略、道具、待命。策略菜单按射程与策略值列出当前真能用的条目，
  群体策略（大援助、大激励…）直接对周围友军施放；火龍書、爆彈这类道具也走同一套策略结算。
- 右键或 Esc：取消。在指令菜单里取消会退回原位，移动作废。
- 点敌军或友军：查看状态和移动范围。
- 按住鼠标左键或单指拖动战场移动镜头；短按松手仍点选部队，拖动松手不会下令。方向键与鼠标边缘卷屏仍可用。
  战况栏右侧的小地图显示三方部队和金色视野框：点击任意位置跳转镜头，拖动金框平移视野；聚焦小地图后方向键也可定位。
  指令菜单、对白和战斗演出期间暂停手动卷屏，避免镜头抢过演出。
- 手机建议横屏游玩：战斗界面紧凑显示，底部「战况／取消／系统」提供触屏入口，系统指令展开后可滚动；
  短按选人、单指拖动镜头、小地图点按均支持触摸，按钮按实际缩放补足触控尺寸；适配安全区及浏览器工具栏尺寸变化。
  竖屏保留完整画面并显示横屏提示，正文仍随原版舞台缩小，尚非重新排版的竖屏版。
- 回车或右下「回合结束」结束我军阶段。
- 右下还有：胜利条件、全军撤退、存档、读档、「镜头跟随」开关、「移动速度」档位，
  以及「音效 開／關」（静音会记住，刷新后仍在）。
  存档列表包含**六个手动档和一个独立自动档**：每格显示关卡／回合、军资、武将数与存档时间。
  手动档可覆盖、可删除（需二次确认）；自动档在开战及每个我军回合开始时更新，只能读取，不能手动覆盖或删除。
  标题、营地、自由交谈房间和战场都能打开列表；闲谈或动作进行中不能写档，商店内可保存并在读档后返回所属房间。
  新档按稳定的战斗／营地／房间 ID 定位；旧营地档依据已存路线标志解析，不能唯一确定时拒绝恢复，不重演奖励和入队。
  战场只在我军阶段、没有部队移动到一半时可手动写入。
  移动速度在「瞬时 / 很快 / 标准 / 慢 / 很慢」间循环，选择会记住。
- **简繁显示**：默认简体，标题和右下系统菜单都有「文字 简体／繁体」开关，随时切换并记住选择。
  原版剧本、武将名、道具与地名的数据仍是繁体，只在显示时转换，存档和规则层不受影响；
  切回繁体是无损还原。**原版像素图里烧死的字**（标题主图、按钮框等）不在文本层，无法转换。
  一键装备全队；战场上进行中还能一键补满我军。改动立即生效，随存档写入。

网址加 `?seed=数字` 可以固定随机种子；开发模式下再加 `&fast` 会跳过动画和对话等待。
开发模式下加 `?demo` 换成不配图的演示流程（两场小战斗，占位画面），用来验证框架本身。

## 结构

```
src/rules/     战斗规则，纯 TypeScript，不依赖画面：数值、移动、结算、回合、AI
src/data/      原版数据：game.json（整部剧本 + 70 关 + 武将）、items.json（道具与转职表）、
               strategies.json（37 条策略）、stages.json（剧情舞台）、
               game.ts（装配成关卡）、items.ts / strategies.ts（查询）、tables.json 数值表；
               sishui.*/campaign.ts 是早期单关演示，测试仍在用
src/audio.ts   音效播放：Web Audio 手势解锁、预加载解码、并发、节流、静音与诊断
src/sfx-map.ts 规则事件 → 音效键的纯函数映射（可单测）
src/music.ts   音乐导演：按阶段 / 场合选曲（战斗、敌军阶段、单挑、败北…）的纯函数（可单测）
src/result.ts  战斗结算：军资拆分、经验与升级、回合数的纯函数（可单测）
src/story.ts   流程脚本解释器：对话、选择、标志、战斗的先后，纯 TypeScript
src/stage.ts   剧情舞台：这一幕该铺哪张图、人摆在哪、点谁说什么（纯逻辑，可单测）
src/facing.ts  棋子朝向：移动后保留方向，旧档与开局默认面向敌方
src/token-art.ts 战场形象：完整 47 列映射，刘备三形态、吕布与曹操专属棋子
src/scene.ts   Phaser 场景：画地图和棋子、播放规则层给出的事件、战斗特写帧动画
src/main.ts    操作流程与界面（标题、剧情、营地、状态栏、菜单、单挑、存读档、胜负与结局）
tests/         自动化测试与浏览器脚本
tools/         原版数据转换、素材生成、浏览器辅助
docs/          框架说明、规则对照表、素材清单、截图
public/assets/sfx/  21 个动作音效 WAV（CC0），来源与授权见 public/assets/CREDITS.md
original/      从原版盘提取的全部资源（58 关地图、240 头像、全兵种/动画/插画/音乐），见 original/README.md
```

玩家和 AI 走同一套行动入口（`src/rules/turn.ts` 里的移动、攻击、策略），合法性检查和结算只有一份。
战斗状态和流程进度都是可以直接 `JSON.stringify` 的对象，存档就是这两样，随机数状态和事件进度都在里面。

## 素材与许可

**画面与音乐逐像素/逐字节取自自己持有的原版《三国志英杰传》繁体中文 DOS/V 版**（58 张战场地图、
19 兵种棋子、240 张武将头像、31 张事件插画、18 兵种 × 150 帧战斗特写、单挑骑将图集、10 首 BGM、
金龙纹界面框与 16 色 VGA 调色板），用 `tools/make_full_assets.py` 从原版提取物裁切、整数倍放大拼成
网页要用的文件，没有重绘。台词与剧情同样是原版剧本转出的。
逐项来源、提取命令和调色板见 [docs/assets.md](docs/assets.md)。界面字体是 OFL 许可的 Fusion Pixel
像素字体（原版 Big5 点阵字库没有现成的 Unicode 网页字体）。

> 原版美术与音乐著作权归 KOEI 及中文版发行方所有。这里只是个人持有原盘、本机自用的复刻研究，
> **不要把替换后的素材公开发布、部署到公网或随仓库分发**。若要公开，用 `tools/make_assets.py`
> 换回 CC0/公有领域的「纸本舆图」版本，步骤见 docs/assets.md 末尾。
