# 三國志英傑傳 · 網頁版

《三國志英傑傳》（KOEI，1995，PC DOS 繁體中文版）的网页版复刻，非官方。
**整部游戏**：从序章「群雄起兵討伐董卓」开始的全部剧情、70 场战斗、营地编成与商店、部队配置（布阵）、
装备与转职、全 37 条策略（含回复、士气、混乱与策略书）、单挑演出、原版 BGM，一直到结局。纯前端，本地存档，无后端。

内容全部是数据，格式见 [docs/framework.md](docs/framework.md)：5491 步流程、610 幕插剧、
70 场战斗、58 张战场地图、129 名武将、63 件道具（价格、回复量、装备加成、8 条转职链）、37 条策略，
由 `tools/build_campaign.py` 从原版盘转出。
规则数据直接读自原版文件，核心规则在原版程序里反汇编核对过；证据、状态和已知差异都在
[docs/rules.md](docs/rules.md)。**可玩不等于已对齐原版**：两个状态分开写在那份文档的开头。

## 命令

```bash
npm install
npm run dev -- --port 5273      # 开发服务器 http://127.0.0.1:5273
npm test                        # 规则层、剧情与整部剧本数据的自动化测试（Vitest）
npm run typecheck               # 类型检查
npm run build                   # 生产构建到 dist/
npm run preview -- --port 5274  # 预览生产构建 http://127.0.0.1:5274
node tests/e2e.mjs              # 浏览器实操验证（需要开发服务器在 5273）
node tests/prod-smoke.mjs       # 生产构建冒烟（需要预览服务器在 5274）

python3 tools/build_campaign.py                            # 原版剧本/战斗/武将/道具/策略 → src/data/*.json
python3 tools/make_full_assets.py <EXTRACT> <PACK>          # 原版图与音乐 → public/assets/**
python3 tools/extract.py "<原版目录>"                       # 单关数据与数值表（早期工具）
python3 tools/make_original_assets.py <EXTRACT> <PACK>     # 单关素材（早期工具）
python3 tools/make_assets.py <四样素材的路径>               # 旧版：换回不含原版素材的 CC0/公有领域画面
```

浏览器脚本用 `~/.cache/ms-playwright` 里的 Chromium；换别的浏览器设环境变量 `CHROME=/path/to/chrome`。

## 操作

- 剧情里点对话框或按回车、空格翻到下一句；章节横幅点一下继续；遇到选择必须点其中一项。
- 出兵准备（营地）：左边编成（必带的人锁定，点「出陣／待命」切换），右边道具（包袱 ↔ 武将 8 格，
  能转职的道具旁有「轉○○」）、武将情报与商店（原版定价，点价钱买），底部「存檔」「出陣」。
- 出陣后是**部隊配置**：点蓝色出兵格依次摆人，点已摆好的收回，「自動配置」按关卡出兵位摆好，
  全摆完才能「開始」。
- 左键点我军部队：选中并显示移动范围。再点范围内的格子移动，点部队自己则原地下令。
  移动时棋子按原版 `HEXZCHR` 的站立 / 迈步两帧逐格交替，走完回到站立帧。
- 移动后弹出指令菜单：攻击、策略、道具、待命。策略菜单按射程与策略值列出当前真能用的条目，
  群体策略（大援助、大激励…）直接对周围友军施放；火龍書、爆彈这类道具也走同一套策略结算。
- 右键或 Esc：取消。在指令菜单里取消会退回原位，移动作废。
- 点敌军或友军：查看状态和移动范围。
- 方向键卷动地图；回车或右下「回合结束」结束我军阶段。
- 右下还有：胜利条件、全军撤退、存档、读档。存档只有一个栏位，只能在我军阶段、没有部队移动到一半时存。

网址加 `?seed=数字` 可以固定随机种子；开发模式下再加 `&fast` 会跳过动画和对话等待。
开发模式下加 `?demo` 换成不配图的演示流程（两场小战斗，占位画面），用来验证框架本身。

## 结构

```
src/rules/     战斗规则，纯 TypeScript，不依赖画面：数值、移动、结算、回合、AI
src/data/      原版数据：game.json（整部剧本 + 70 关 + 武将）、items.json（道具与转职表）、
               strategies.json（37 条策略）、game.ts（装配成关卡）、items.ts / strategies.ts（查询）、
               tables.json 数值表；
               sishui.*/campaign.ts 是早期单关演示，测试仍在用
src/story.ts   流程脚本解释器：对话、选择、标志、战斗的先后，纯 TypeScript
src/facing.ts  棋子朝向：面向敌方
src/scene.ts   Phaser 场景：画地图和棋子、播放规则层给出的事件、战斗特写帧动画
src/main.ts    操作流程与界面（标题、剧情、营地、状态栏、菜单、单挑、存读档、胜负与结局）
tests/         自动化测试与浏览器脚本
tools/         原版数据转换、素材生成、浏览器辅助
docs/          框架说明、规则对照表、素材清单、截图
original/      从原版盘提取的全部资源（58 关地图、240 头像、全兵种/动画/插画/音乐），见 original/README.md
```

玩家和 AI 走同一套行动入口（`src/rules/turn.ts` 里的移动、攻击、策略），合法性检查和结算只有一份。
战斗状态和流程进度都是可以直接 `JSON.stringify` 的对象，存档就是这两样，随机数状态和事件进度都在里面。

## 素材与许可

**画面与音乐逐像素/逐字节取自自己持有的原版《三国志英杰传》繁体中文 DOS/V 版**（58 张战场地图、
19 兵种棋子、240 张武将头像、31 张事件插画、18 兵种 × 150 帧战斗特写、单挑骑将图集、10 首 BGM、
金龙纹界面框与 16 色 VGA 调色板），用 `tools/make_full_assets.py` 从原版提取物裁切、整数倍放大拼成
网页要用的文件，没有重绘。台词与剧情同样是原版剧本转出的。
逐项来源、提取命令和调色板见 [docs/assets.md](docs/assets.md)。界面字体是 OFL 许可的 Fusion Pixel
像素字体（原版 Big5 点阵字库没有现成的 Unicode 网页字体）。

> 原版美术与音乐著作权归 KOEI 及中文版发行方所有。这里只是个人持有原盘、本机自用的复刻研究，
> **不要把替换后的素材公开发布、部署到公网或随仓库分发**。若要公开，用 `tools/make_assets.py`
> 换回 CC0/公有领域的「纸本舆图」版本，步骤见 docs/assets.md 末尾。
